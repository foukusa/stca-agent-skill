Long description:
Use Sliding Threshold Correlation Analysis (STCA) for polymer repeat units. In published-rule mode, apply frozen Tg and EC structural rules that retain the paper's ECFP2-split provenance; select an explicit profile and percentage tier. In custom-data mode, derive a new rule family from user-supplied measured data with user-defined percentages and declared source/evaluation roles. The skill also exports executable constraints for agent-assisted candidate design and verifies every proposal. It preserves the original star-containing repeat-unit SMILES, uses H-cap only as a calculation representation, accepts optional arbitrary row identifiers, and calls the pinned polymer-stca implementation. A Python/RDKit execution environment is required.

Starter prompts:
1. Apply the published Tg top-20% and EC-low bottom-10% rules to this polymer candidate table, then report the same-candidate intersection and every failed condition.
2. Derive STCA rules from this measured dataset using the explicit percentage thresholds and source/evaluation roles I provide, then export the complete rule family and frozen model.
3. Export the selected frozen STCA constraints, propose repeat-unit candidates, preserve the original star-containing SMILES, and verify every proposal after H-cap/MACCS calculation.
