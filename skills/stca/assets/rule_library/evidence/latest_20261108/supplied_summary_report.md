# STCA skill 优化与开源数据集测试总结

2026 年 11 月 8 日

## 1. 概要

本报告整理 STCA agent skill 的修订方案、自动数据层的规则，以及在 12 个开源聚合物数据集上的筛选与评价结果。修订的核心有两点。一是由 skill 自己完成数据清洗、数据形式判断和扫描参数选择，用户只需提供结构、性质、单位、方向和百分位档位，所有档位在输出中都同时给出物理单位下的数值阈值。二是把 STCA 与 WRAcc 子群发现集成起来，每个档位以平均分数 AS 较高的方法为主推规则，同时给出另一种方法的规则与分数供用户选择。评价在用户自己的数据范围内进行。

主要结论有四点。第一，自动数据层在 12 个数据集上无需人工干预即可运行，并能自动识别对规则有决定性影响的不合理记录。第二，在 36 个档位上，STCA 的平均 AS 为 0.486，WRAcc 为 0.539，集成流程的嵌套估计为 0.552，高于任一单独方法；STCA 的平均精确率为 0.562，高于 WRAcc 的 0.509，但 F1 与 MCC 较低，选择更保守。第三，STCA 在 15 个档位上主推，覆盖两种实验气体渗透率、RadonPy 热导率和 ADEPT 密度的全部档位；WRAcc 在 21 个档位上主推，覆盖折射率、介电常数和 ADEPT 热导率的全部档位。第四，除气体渗透率外，测试数据均为 MD 或 DFT 模拟值，与论文所用的实验数据存在系统差异，结论只作方向性参考。

## 2. skill 的定位

修订后 skill 以自定义数据模式为核心，即用户用自己的数据归纳规则，并在自己的数据范围内筛选与评价。规则引导的候选生成建立在这些自定义规则之上。已发表规则模式的适用范围限定为与论文同类的数据，即同一性质、可比实验条件下的测量值；论文规则来自 PoLyInfo 的实验 Tg 与 EC，对其他性质、模拟数据或测量方式明显不同的数据，属于探索性用法，需要先在带标签的数据上检查，不作无条件推广的宣称。

## 3. 自动数据层规则

### 3.1 数据清洗

| 步骤 | 规则 | 处理方式 |
|---|---|---|
| D1 结构检查 | SMILES 无效，或连接点 `*` 不是末端单键连接到重原子 | 排除 |
| D2 加工记录 | 元数据出现甲醇处理、老化、热处理、退火、交联、等离子体聚合、辐照、拉伸取向、共混、复合等关键词 | 该次测量排除 |
| D4 重复测量 | 同一结构 3 次以上测量时，偏离中位数超过 3 个稳健标准差的测量剔除 | 其余取中位数 |
| D5 近邻一致性 | 与 ECFP4 近邻（Tanimoto ≥ 0.5）中位数相差超过 4 个稳健标准差 | 只标记 |
| D6 合理范围 | 超出性质登记表给出的合理范围 | 只标记 |
| D7 尾部影响 | 最严档位中被 D6 标记的记录逐条留一重拟合，代表规则条件集合的平均 Jaccard 变化 ≥ 0.3 | 自动隔离并列出 |

近邻不一致只标记而不删除，因为它既可能来自录入错误，也可能来自真实的结构突变。只有同时满足“超出合理范围”和“对规则有决定性影响”两个条件的记录才会被隔离。这一规则在 O2 渗透率数据上自动隔离了两条记录（72,000 Barrer 的聚 1-己烯和 61,000 Barrer 的聚环己烯，规则变化分别为 0.61 和 0.43），其余尾部记录的影响均为 0。隔离前后的结果如下（与 5.3 节相同的评价协议，AS = (MCC + Precision + F1) / 3）。

| O2 渗透率档位 | 不执行 D7 的阈值 | STCA AS | WRAcc AS | RF AS | 执行 D7 的阈值 | STCA AS | WRAcc AS | RF AS |
|---|---|---|---|---|---|---|---|---|
| 前 30% | ≥ 62 Barrer | 0.63 | 0.65 | 0.80 | ≥ 61 Barrer | 0.64 | 0.63 | 0.80 |
| 前 20% | ≥ 206 Barrer | 0.55 | 0.59 | 0.76 | ≥ 203 Barrer | 0.58 | 0.60 | 0.77 |
| 前 10% | ≥ 997 Barrer | 0.57 | 0.48 | 0.55 | ≥ 967 Barrer | 0.73 | 0.47 | 0.58 |

两条记录只占 302 个结构的 0.7%，却使 STCA 前 10% 档的 AS 从 0.57 提高到 0.73，而 WRAcc 与 RF 的变化不超过 0.03。不执行 D7 时，30% 与 20% 档的主推方法是 WRAcc；执行后三个档位都由 STCA 主推。STCA 的阈值扫描对尾部误差最敏感，因此 D7 是 skill 必须具备的能力。

### 3.2 数据形式与单位

skill 内置性质登记表（`assets/property_registry.json`），记录每种性质的标准单位、单位换算、是否取对数和合理范围。登记表标记为对数尺度的性质（电导率、六种气体渗透率）直接取 log10；未覆盖的性质只有在全部为正且 log10(p99/p1) ≥ 2 时才取 log10。本次测试中两种气体渗透率自动取 log10，其余 10 个数据集保持原尺度。

### 3.3 数据角色

Morgan 指纹默认半径为 2（即 ECFP4，2048 位），经 t-SNE 降到二维（random_state 42，perplexity = min(30, max(5, n//4))），按到中心的距离取外侧 20% 为外推集。同一 H-cap 结构不跨角色。在 source 内部按同样方法再分出伪外推集，只用于扫描设置的选择。用户提供角色时优先使用用户角色。

### 3.4 扫描设置

数值网格在扫描范围内约 500 个点，步长向下取整到 1、2、5 × 10ⁿ；若任一步内的记录超过 source 的 1%，步长减半，最多四次。最小子集在 1 与 source 的 5%（即最严 10% 档正例数的一半）之间选择，依据是伪外推集上三档平均 MCC，两者相差小于 0.05 时取 1。下表是这一规则在可选外推检验的 23 个可评价单元上的效果。

| 最小子集设置 | 23 个可评价单元的平均外推 MCC |
|---|---|
| 固定为 1 | 0.296 |
| 固定为 source 的 5% | 0.385 |
| 嵌套自动选择（采用） | 0.389 |

### 3.5 数值化档位、评价与集成

每个百分位档位都换算为全量数据上的数值阈值和单位，这是用户在自己数据范围内筛选时使用的阈值。导出的规则和提示词同样写明数值阈值和单位，例如“前 10%，即 CO2 渗透率 ≥ 5,310 Barrer”。

评价在数据范围内进行，按结构分组做 5 折交叉验证并重复 3 次，汇总折外预测，逐档报告 Precision、Recall、F1、MCC 和 AS = (MCC + Precision + F1) / 3 的均值与标准差。AS 与 STCA 选择代表规则时使用的标准一致。选择 5 折的原因是最小的数据集（CO2，242 个结构）在 10% 档只有 25 个正例，5 折时每个测试折约有 5 个正例；同时训练部分占 80%，与外推检验的划分一致。改为 10 折时，36 个档位的 AS 平均变化为 0.015（STCA）和 0.011（WRAcc），最大变化 0.042 和 0.066，两种方法的优劣在 97% 的档位上不变；重复 3 次的 AS 标准差平均为 0.024 和 0.013。折数因此不影响结论。

STCA 与 WRAcc 子群发现（最多 3 个条件）集成为一个规则交付流程。每个档位以交叉验证 AS 较高者为主推规则，差值在 0.02 以内时保留 STCA；另一种方法的规则与分数作为备选同时输出，供用户选择。集成流程本身的表现用嵌套方式估计，即在每个训练部分内部再做分组 3 折来选择方法，再到外层测试折上评价。全量数据正例少于 20 的档位标为“不可评价”。t-SNE 外侧 20% 的外推检验只作为可选补充，结果放在附录。

### 5.6 规则引导的候选生成

以 ADEPT 单体能隙的全量数据重新训练规则，前 10% 档（≥ 12.90 eV）的代表规则为“含氟（K42），同时不含环原子、氮与杂原子相连、氮双键、硫的三连接中心、环外氧、环内氮，且氮原子不超过一个”，即无环含氟脂肪族结构。该规则在训练数据上的精确率为 0.64，召回率为 0.28。导出的约束文件和提示词写明了性质名称、单位与数值阈值。

宿主按约束提出 20 个重复单元，skill 的冻结规则核验判定 20 个全部满足约束，作为对照的 4-氟苯乙烯（含苯环）被正确拒绝。20 个提案中有 13 个已存在于数据集，其中 12 个高于 12.90 eV（数据集基线比例为 10%）；由于这 13 个结构都在训练数据中，这一比例只说明规则准确描述了高能隙区域，不构成前瞻性验证。另外 7 个为新结构，没有标签。

## 6. 结论

自动数据层可以承担绝大部分数据处理工作，包括结构检查、加工记录剔除、重复测量合并、单位换算、对数变换、扫描步长和最小子集选择，用户不需要手动清洗或调参。尾部影响隔离能自动找出极少数对 STCA 规则有决定性影响的不合理记录。

STCA 与 WRAcc 的集成比任何单一规则方法都好，嵌套估计的平均 AS 为 0.552。两者的分工比较清楚。STCA 在实验气体渗透率、RadonPy 热导率和 ADEPT 密度上占优，精确率普遍更高；WRAcc 在折射率、介电常数、单体能隙的宽松档位和 ADEPT 热导率上占优，召回率与 F1 更高。随机森林的预测更准，但不提供可读规则。对外介绍 skill 时，应按这些具体结果描述适用场景。

## 7. 局限与下一步

除两种气体渗透率外，测试数据全部是 MD 或 DFT 模拟值。经典 MD 会高估比热容，ADEPT 的能隙是单体 HOMO–LUMO 差而非聚合物带隙，MD 静态介电常数包含噪声较大的偶极涨落项，这些系统偏差会改变排在顶端的结构。STCA 对尾部标签误差敏感，模拟数据中的尾部噪声可能使其表现被低估，但在实验数据上验证之前，不能据此推断其实验表现更好。

建议的下一步有三项。其一，在与论文同类的实验数据上检验已发表规则模式，例如 LAMALAB 整理的实验 Tg 数据集，在去除与 PoLyInfo 训练集重叠的结构后评价。其二，为 Yang 等仓库中 MSA 总表的约 1,200 条 CO2 和 O2 实测记录补全结构，扩大实验气体数据。其三，把 scikit-learn 写入锁定环境，并在 GitHub 上合并本次修订。
