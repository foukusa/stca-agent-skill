# 主推与备选规则清单

每个数据集、每个档位给出主推规则（交叉验证 AS 较高者，差值在 0.02 以内时为 STCA）和备选规则。规则均在全部数据上训练。条件写作 MACCS 键编号与要求值，SMARTS 为 RDKit MACCS 定义；计数参数大于 0 的键，表示匹配次数超过该值才记为存在。交叉验证分数为分组 5 折重复 3 次的均值。
