# 数据来源与许可

| 数据 | 来源 | 许可 | 压缩包中的内容 |
|---|---|---|---|
| CO2、O2 气体渗透率（实验） | github.com/jsunn-y/PolymerGasMembraneML，datasets/datasetA_imputed_all.csv（Yang 等，Science Advances 2022） | MIT（Copyright 2021 Jason Yang） | 清洗后的逐结构表、审计文件、档位表 |
| RadonPy PI1070（全原子 MD） | github.com/RadonPy/RadonPy，data/PI1070.csv | BSD-3-Clause（RadonPy developers） | 清洗后的逐结构表、审计文件、档位表 |
| ADEPT 热导率、密度、介电常数、折射率（MD），单体能隙（DFT） | github.com/sobinalosious/PolyGraphMT，data/raw/ | 仓库未附许可文件 | 只含审计文件、档位表和统计结果，不含逐条记录；可用 05_复现脚本 重新生成 |

使用上述数据发表结果时，请引用原始来源。性质登记表中的合理范围为近似值，仅用于标记，不作为数据真值。
