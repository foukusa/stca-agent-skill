# 规则选择与筛选评价

STCA 提供作者论文中实现的 Tg、电导率规则，以及基于公开 GAS、RadonPy 和 ADEPT 数据归纳并验证的规则。来源与在线复现入口见[论文、代码与数据来源](provenance.md)。

## 如何选择

先选择性质、方向和目标百分比。归纳自己的数据时，未指定百分比直接采用10%、20%、30%；也可使用15%、25%等自定义档位。每档显示对应的具体物理阈值、比较符与单位。

## AS 与方法推荐

AS（Average Score）是作者 STCA 论文提出并在筛选任务评价中验证使用的综合衡量指标：`AS = (MCC + Precision + F1) / 3`。本 skill 沿用该定义，在相同数据与目标档位上比较 STCA 和 WRAcc，分别返回规则、筛选结果和推荐理由。

两种方法均可评价时，WRAcc 的 AS 高出 STCA 超过0.02才列为主推，否则保留STCA。用户可接受推荐，也可指定使用任一种方法。

新学习默认在训练数据内部选择 WRAcc 的条件数，并同时保留 STCA 与 WRAcc；也可指定“最多 10 个条件”或“不限制条件数”。更长不等于更高的验证分数，方法推荐仍依据实际评价。已有冻结规则保持原条件。

## 查看结果

每种方法分别返回原始结构、入选/未入选/不可计算状态，以及每条未满足的规则条件。保存后的规则可以继续筛选新候选，也可交给当前 LLM 生成候选并核验。原始星号连接点保留，氢封端只用于计算。

有标签数据可查看Precision、Recall、F1和MCC；没有标签的候选只判断结构规则匹配情况。选择与你的目标和测量/计算条件相符的规则。
