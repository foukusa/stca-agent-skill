# STCA：WorkBuddy 使用说明

版本 **0.1.0**。启用 STCA 后，使用自然语言和上传文件完成任务；由 AI 助手读取规则、管理后台计算并交付结果。

## 安装与开始

在 WorkBuddy 的 skill 管理界面直接上传 `stca-workbuddy-0.1.0.zip`，导入并启用 STCA。无需解压或重新打包；不要套入额外文件夹。首次调用时由 AI 助手通过随包启动入口查找 Python 并准备完整运行资源，后续仍用自然语言操作。计算时自动检查 RDKit 与所需依赖，不要求用户填写 Python 路径。

输入 **“开始使用 STCA”**，选择：

1. 上传自己的文件总结规则。
2. 根据已有规则直接筛选。
3. 根据已有规则直接生成。

用户只选 2 或 3 时，先显示“我的规则”和内置规则目录，按来源、性质、方向与百分比选择；不自行指定默认项。已明确说“刚保存的规则”等指代时直接执行。用户无需知道规则编号或计算命令。

## 生成方式

选定规则后，选择“先查看并调整 prompt，确认后生成”或“直接生成并核验”。前者展示完整文本并接受修改，明确确认后调用当前 LLM；后者立即调用当前 LLM。两者均保存全部候选并逐条核验，给出通过项和未满足的规则条件。用户已说明方式时直接执行，不要求配置模型 API。

## 简短范例

| 任务 | 可以直接发送 |
|---|---|
| 上传归纳 | “1。从这份计算热导率数据总结高值规则，单位 W/(m K)。” |
| 规则筛选 | “2。先给我可选规则目录，用我选的规则筛选这份候选表。” |
| 规则生成 | “3。”选择目录中的规则后说：“直接生成 10 个候选并核验。” |
| 使用新规则 | “用刚保存的规则继续筛选这份新候选。” |
| 复制 prompt | “把选中规则的完整中文生成 prompt 给我。” |

归纳后默认返回上传表每档完整筛选结果、入选子表、实际阈值和逐条未满足的规则条件，保留原始星号结构并标明数据角色。随后保存规则、完整双语 prompt 和可下载规则包，返回主菜单。说“上一级”会保留已有文件与规则。

更完整的对话与交付示例见 [usage_examples.md](usage_examples.md)。换会话或平台时可上传先前下载的规则包继续使用。计算准备见 [platform-runtime.md](platform-runtime.md)；平台不能执行时不声称已完成核验。
