## 表示

- 原重复单元 SMILES 保留，末端单键通配原子 H-cap 后计算 MACCS167。K0 空位与 K1–K166 编号不变；上游低层 MACCS 只读已经准备好的结构。
- H-cap 是计算副本，最终返回原始带 `*` 结构。不可根据 capped 分子猜测连接点；H-cap 碰撞不是聚合物等价证明。
- 论文化学空间划分使用 2048 位 Morgan radius=2（ECFP4-like）；原 `tsne_pro.py` 的 radius 是半径，ECFP 名称使用直径。不要把 radius 改成 1。此分割表示与 MACCS 规则表示分开。
- 新候选筛选不重新划分。严格论文复现复用原成员与协议；在新数据上重新 t-SNE 并不是原成员复现。

## 原始算法

高方向扫描 `s=y`，低方向扫描 `s=-y`。每个有效阈值 t 保留 `s>=t` 的样本，计算每个二值子结构在该嵌套子集中的出现频率。相关性是阈值与频率轨迹之间的 Pearson 系数，不是单次二分类标签与 bit 的相关性。

value 网格从方向变换后目标的极值及步长建立，只保留样本数满足 `min_subset_size` 的阈值。至少四个有效点。原实现存在 `unique`/`quantile` 模式，但不能因 value 效果差便自动切换。保持名义 p 筛选、恒定特征排除、正负榜及平局次序与固定源码一致。

正榜前 a 个特征要求为 1，负榜前 b 个要求为 0，以 AND 连接。保留纯正、纯负、混合前缀；不跳过中间排名，不做任意子集搜索、beam、OR 或多数投票。正负深度 p/q 时池大小为 `p+q+p*q`。

通用/Tg 家族按 source F1 排序保留纯正、纯负、混合代表及补足成员。EC 的命名 paper/source_locked 配方使用 V15 前缀长度模板，不能把其他性质套入该模板当作 EC 配方。低 EC 的方向扫描及高 EC 的榜单交换由原配方完成，冻结规则不再次翻转。

## 协议

| 名称 | 代表选择 | 解释 |
|---|---|---|
| `paper` | 原 source/selection/合并范围的核心调和分数 | 恢复论文规则；selection 标签参与，不能称最终盲测 |
| 命名 `source_locked` | 对应 Tg/EC 配方，只用 source AS | 与 paper 不同代表；保留原配方身份 |
| 自定义 generic | 原前缀家族及 source AS | 任意有标签性质上的应用，不伪称命名 paper/source_locked 配方 |
| 自定义 adaptive | generic 核心 + 有记录的源内尺度/扫描设置选择 | 适配器配置变体，不能覆盖论文结论 |

`AS=(MCC+precision+F1)/3`。有效性与支持数等判据由上游配置负责；评价正例不足 20 的标记不是新规则拒绝条件。

每 tier q，原训练空间 cutoff 是 high 的 `quantile(y,1-q)` 或 low 的 `quantile(y,q)`，边界包含等于，线性分位插值。ties 会使正例比例不等于 q；q 也不约束新候选最终选中比例。没有默认 5%。

## 数据适配与新性质

详见 [custom_data.md](custom_data.md)。适配层不能改上游相关性与家族逻辑。它负责：

1. 只从 source 决定是否取对数及 value 步长；不把 Tg/EC 的量纲步长复制到气体渗透率、密度或带隙。
2. 保留原始单位和真实目标名，避免保存成 `p`/`u`。
3. 给出有界网格和常数/离散值诊断；不因失败静默切换扫描类型。
4. 显式 nested 策略仅使用 source 内预先给定的 inner roles 选择支持量，再在全 source 拟合；外评标签不参与。
5. 只标记处理历史、重复冲突、离群与表示碰撞；不自动排除、聚合或以邻居标签“纠正”数据。

若 y_model=log10(y_physical)，模型 cutoff 的物理值为 `10**cutoff_model`。低方向仍直接以原性质“小于等于 cutoff”解释，不把负号误写入物理单位。已是 log 的输入需明确 `already-log` 及原单位，不重复转换。

## 评价

冻结后默认 `fixed_train`。`dataset_relative` 用评价集自身分位重定义真实标签，规则不变；两者记录到不同结果。显式绝对 cutoff 评价也不等于重新学习绝对阈值规则。

输出 TP/FP/TN/FN、Precision、Recall、F1、MCC、coverage、富集、实际目标数量、cutoff 与单位。无标签只有规则符合率。零正例、零负例或零预测类别导致部分指标无定义时，保留状态/原因，不用宽泛异常捕获转成 0 分。

少量正例、单一结构簇占比过高或尾部规则不稳使泛化判断薄弱；它们不禁止结构筛选。20 正例阈值是诊断启发式，不能伪装成已验证的统计定理。检查原始 canonical 及 H-cap 重叠，不能以随机 ID 无重叠宣称结构无重叠。

## 迁移和多目标

跨性质和跨来源不是同一证据。Tg→TC、EC→介电常数必须标明规则原性质和目标性质，并取得用户声明的迁移意图。原论文某个数据支持的关系不能自动推广至所有模拟/实验数据。

对新性质优先使用新标签提取自己的规则。同性质跨来源评价需要单位、测量/模拟条件和结构重叠审计。多目标结构交集始终在同一候选行执行；没有同条件配对标签就没有真实联合精度。

约束导出使用精确 bit 定义并保留 AND 逻辑。MACCS key 可能是计数或特殊逻辑，不能都替换为一次 SMARTS。平台生成后仍须实际执行指纹和冻结规则，结构符合不等于实测性能确认。
