# DeepSeek Harness 与 WorkBuddy

两个平台采用相同的 STCA 计算核心、H-cap、冻结模型协议和公开验收。平台差异只在安装入口、SKILL.md 展示字段与宿主操作说明。

- 在 DeepSeek Harness 中使用时，读 [deepseek-harness.md](deepseek-harness.md)。
- 在 WorkBuddy 中使用或准备市场提交时，读 [workbuddy.md](workbuddy.md)。
- 准备运行环境时，读 [platform-runtime.md](platform-runtime.md)。该文提供 macOS/Linux 与 Windows 命令，并说明如何复用安装器输出的实际环境路径。

两个平台发行包共用相同的目标规划、H-cap、规则提取和候选筛选脚本。安装或导入完成后，先确认宿主能够发现 STCA skill，再在用户工作目录中处理实际输入；不能用文字推演代替脚本执行。
