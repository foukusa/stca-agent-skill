# 自动数据准备与方法选择

版本 0.1.0。新学习默认执行 `morgan_evaluation.py`：先按结构划分，再仅用 source 标签准备和训练。不得将全量准备后的随机交叉验证称为结构外推。用户只需自然语言上传数据、说明目标。

## 先划分，再准备

对 H-cap 计算副本使用 ECFP4（Morgan radius=2、2048 位），按原始 canonical 结构、相同 H-cap 副本及明确材料组保护整组。性质数值和随机 ID 不用于选择结构域。默认外部 holdout 每条结构到 source 的最近邻 Tanimoto 距离至少 0.5；边界 buffer 单独记录，不参与拟合或外部评分。核对实际距离及无组重叠，不能用 t-SNE 坐标距离替代。

仅向 source 传入 `auto_data_layer.prepare_dataset`，每个百分比独立执行单位处理、D3 变换、D4 可比重复观测清理、D7 影响诊断及 C1 扫描选择。D5 近邻和 D6 范围只标记，不因希望提高得分删除有效记录。原结构与条件均相同才允许聚合；H-cap 相同不能合并连接位置不同的结构。已 log 输入先还原物理尺度，再换单位，防止重复取 log。

source 内再以 Morgan 距离划分训练/验证；内部训练之外的标签不得用于该次准备或选规则。按内部验证比较 STCA 和 WRAcc，冻结推荐，再在外部 source 准备和拟合最终规则。外部 holdout 只在冻结后评价，不用其分数选方法、档位、步长、长度或数据清理政策。

## 评价与交付

source 标签分位数得到每档物理阈值；同一阈值用于两方法及 holdout，不从候选或 holdout 重算。平均筛选评分为（马修斯相关系数 + 精确率 + F1）/3；source 内验证中 WRAcc 高出 STCA 超过 0.02 才主推 WRAcc，否则优先 STCA。两种方法均交付，方法选择不是 OR/AND 融合。

报告结构划分、buffer、source 准备、内部推荐、独立 holdout 表现和原表回筛各自的范围。距离划分不可行、无有效规则、单一标签类或指标未定义均保留原因，不填伪零，不随机回退。每档独立准备，增加或重排其他档位不得改变这一档。

H-cap 仅用于 MACCS 和距离计算副本；结果读取保存的原始星号 SMILES，不从封端副本反推连接点。有效规则保存模型、完整中英文 prompt 和便携包，核对实际保存状态后继续筛选或生成。

## 明确旧协议时

用户明确要求范围内随机保护组评价时才调用 `inrange_evaluation.py`，并注明准备和扫描已由该次输入确定，不能解释为严格结构外推。用户明确提供原论文成员、固定 source/holdout 或旧 t-SNE 协议时保留其参数，通过 `auto_screen.py`/`custom_fit.py` 执行，并按实际距离核验其能否称为严格 Morgan 留出。历史结果保持其原协议身份。
