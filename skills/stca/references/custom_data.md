# 自己的数据：归纳、评价与保存

## 默认 Morgan 距离路径

用户上传原始聚合物 SMILES 与数值性质列，说明方向、单位及实验/计算含义。由 `morgan_evaluation.py` 先用结构建立 source、holdout 和必要的 buffer，再仅用 source 标签准备和训练 STCA、WRAcc。ECFP4 为 radius=2、2048 位 Morgan 指纹；默认每条 holdout 到实际 source 的最近邻 Tanimoto 距离至少 0.5，相同原始结构及 H-cap 副本不跨界。

在 source 内另做 Morgan 距离验证，选择方法；外部 source 再独立准备并训练冻结规则。变换、扫描步长、支持量、WRAcc 条件数与档位推荐均不得读取外部 holdout 标签。每个百分比独立准备。source 内两方法的平均筛选评分为（马修斯相关系数 + 精确率 + F1）/3；WRAcc 高出 STCA 超过 0.02 才切换，否则保留 STCA。两方法不自动相交或求并集。

每档交付 source 得到的具体物理阈值、比较符、单位、两方法规则及可用状态、独立留出评分、完整原表筛选和入选子表、模型及双语生成 prompt。原表回筛包含训练记录，不是独立外推表现。学习后可以直接筛选新候选或按选定规则调用当前 LLM 生成。

## 数据、单位和身份

保留原始 CSV 全部文字值、列、ID、星号结构及处理映射。ID 不构成材料身份。只有原始 canonical 结构及可比条件一致才合并重复观测，不能因 H-cap 相同而合并不同连接位置。加工历史、近邻不一致、合理范围和尾部影响分别记录；范围或近邻标记本身不能触发删除。

agent 先绑定结构列、目标列和单位；用户明确列名优先，多列歧义先询问。已 log 数值不可重复取 log；未知性质可用用户明确给出的单位。元数据处理只针对样品加工描述；Reference、DOI、Journal 保留为来源，不能当加工历史扫描。

保留原始带 `*` SMILES，H-cap 只用于计算副本；输出从原始列取回星号结构，不反推连接点。缺少性质但结构有效的记录仍可回筛，只是不参与真值评价。

## 百分比与状态

用户可自定 0% 与 100% 之间的任意百分比；未定义使用 10%、20%、30%。百分比定义 source 标签目标尾部，不是候选入选配额。内置目录没有的档位需学习，不能插值或换成邻近规则。固定绝对目标保持用户值。

距离划分不可行、无有效规则、零入选、零 TP、单一标签类、计算错误及指标未定义分别报告；不得静默回退到随机五折。无规则不是空条件全选。保存完成后交付真实名称、文件位置和便携规则包，继续当前对话；跨会话上传规则包载入。

## 用户明确给出其他协议

保留用户提供的角色和固定设置。旧 `inrange_evaluation.py` 是条件性的范围内保护组随机评价；`auto_screen.py`/`custom_fit.py` 可执行显式角色或旧投影外围协议。这些结果只使用准确协议名称，不改称严格 Morgan 距离外推，也不覆盖作者论文冻结规则。
