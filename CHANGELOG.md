# Changelog

## 0.1.2 — 2026-11-07

- Replaced the Chinese landing page with an English `README.md` and added a complete `README.zh-CN.md` translation.
- Added a linked table of contents at the beginning of both README files.
- Reorganized the landing page around installation, explicit invocation, inputs, outputs, and the three STCA workflows.
- Separated GitHub source installation from platform release artifacts: the repository tree is used directly by `skills.sh` and clones, while platform ZIPs are generated locally and attached to releases or submitted to their platforms.
- Added explicit invocation examples for ChatGPT (`@STCA`), Codex (`$stca`), DeepSeek Harness (`/stca`), WorkBuddy, and other Agent Skills hosts.
- Removed the obsolete external-archive files and packaging instructions.
- Kept the STCA logo in the English and Chinese README files and in all platform packages.

## 0.1.1 — 2026-11-07

- Led the public documentation with the three usable STCA workflows and platform roles.
- Added independent objective planning for Tg, Tm, Td, TC, EC, and ε-AC, including per-property direction, tier, and cutoff mapping.
- Replaced the fixed joint example with user-driven objective planning and same-candidate rule intersection.
- Reduced the packaged logo to 512 × 512.

## 0.1.0 — prepared 2026-11-07

- Added published-rule screening, measured-data rule extraction, and rule-guided candidate verification workflows.
- Added H-cap preparation while preserving the original input column.
- Added explicit `paper` and `source_locked` protocol handling.
- Added GitHub, ChatGPT/Codex, DeepSeek Harness, and WorkBuddy release packaging.

This preparation history does not assert that version 0.1.0 was publicly released.
