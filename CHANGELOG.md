# Changelog

## 0.1.0

- Current open-data rules now follow the supplied 12-task in-range study: 36 target tiers with explicit STCA/WRAcc primary and alternative rules.
- Added protected-group CV, transparent data preparation, explicit frozen literal models and full save/screen/generate support for both methods.
- Kept historical source/holdout adapters and older rule IDs separate from the current full-data rule evidence.

- Uploaded-data learning now returns per-tier screening of every original row, selected tables and failed conditions automatically.
- Generation begins with a user-selectable rule directory; complete bilingual usage examples and structure-only input examples are included.
- User packages no longer include the author publishing guide or publishing walkthrough.

- Learn, save and return: user-created rules persist in a separate workspace library and can be exported/imported.
- Main menu order: upload data to learn; screen with existing rules; generate with existing rules.
- Unified OpenAI skill package and one public plugin submission for ChatGPT and Codex.
- Original trial candidate screening (20/21 matches) is tracked separately from later fitted-model evaluations.

- Three built-in task choices and short requests; rule IDs and prompt assembly stay internal.
- Downloadable ChatGPT, Codex, DeepSeek and WorkBuddy installation ZIPs are included in the GitHub source package.
- One regular AD_GAP entry per percentage, with compatibility variants retained internally.
- Per-rule recorded evaluation status distinguishes supported screening cases from weak or zero-coverage results.

- Compatible Python 3.10+ CPU runtime with functional checks and host-managed setup; exact historical dependency locks are optional.
- Every workflow starts from natural language, including automatic prompt export, host-LLM generation and candidate verification.

- Three natural-language workflows: apply bundled rules, learn rules from an uploaded CSV, and generate new repeat units with complete LLM prompts.
- A rule library with 77 frozen rule options and 154 ready-to-copy English/Chinese generation prompts.
- Paper Tg/electrical-conductivity rules and open-data rules for 13 property tasks from gas-permeability, RadonPy and ADEPT datasets.
- Host-managed runtime discovery and preparation; browsing rules and copying prompts require no scientific dependencies.
- Automatic data preparation, ECFP4-based data roles, target-scale and scan-step selection, reusable models and physical boundaries.
- Exact condition checks for each candidate, multi-rule intersections, arbitrary identifiers and original star-containing SMILES.
- English and Chinese user guides, platform packages and the STCA logo.
