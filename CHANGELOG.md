# Changelog

## 0.1.0 — prepared 2026-11-07

- Added published-rule screening, measured-data rule extraction, and rule-guided candidate verification workflows.
- Added H-cap as a calculation-only representation while preserving the original star-containing repeat-unit SMILES as the final presentation structure.
- Added arbitrary, configurable identifier-column handling; PoLyInfo `PID` is not required.
- Added automatic row identifiers for candidate screening when no identifier column is supplied.
- Added explicit `paper` and `source_locked` protocol handling.
- Added independent objective planning for Tg, Tm, Td, TC, EC, and ε-AC.
- Added English `README.md`, complete Chinese `README.zh-CN.md`, linked tables of contents, and explicit platform invocation examples.
- Added GitHub, ChatGPT/Codex, DeepSeek Harness, and WorkBuddy release packaging with the STCA logo.

This is the initial `0.1.0` release package.
