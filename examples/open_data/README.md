# More application examples

[中文](README.zh-CN.md) · [Main guide](../../README.md) · Version **0.1.0**

The STCA skill includes **77 frozen rules and 154 English/Chinese generation prompts**, covering all **13 public-data property tasks** with ready-made rules. Open the [rule and prompt directory](../../docs/RULE_LIBRARY.md) to choose one, or upload your own property CSV to learn a new rule and check candidates generated by an LLM.

Every example uses natural-language requests. The agent handles data, backend preparation, rules and prompt export; calculations use a CPU and generation uses the current host LLM.

## Find and apply an existing rule

Ask the installed skill for its current catalog:

```text
List STCA's built-in rule sets with their datasets, properties, directions
and available percentages. Tell me what candidate file each needs.
```

The catalog includes 11 paper rules, five tiers for each of 13 public-data tasks (65 rules), and one author-supplied monomer-gap rule. Every public-data task offers high-value Top 10%/15%/20%/25%/30% rules. The data sources below can also support learning a new direction or percentage.

After selecting an entry, upload a candidate CSV and ask:

```text
Apply the rule I selected to my uploaded candidates.csv.
Its structure column is SMILES; keep my original * connection points.
Return matching candidates and every failed condition.
Also give me a complete prompt for generating more candidates with this rule.
```

## Gas separation membranes

For an available CO2-permeability rule, you only need new candidates:

```text
Show me STCA's built-in high-CO2-permeability rules and their available percentages.
I want to screen candidates.csv using its SMILES column.
Once I select a percentage, return the matching structures and a generation prompt.
```

To learn from your own measurements:

```text
Use STCA to learn high-permeability rules from my uploaded gas.csv.
Structure column: SMILES; experimental target: CO2; unit: Barrer.
Explore Top 10%, 15%, 20%, 25% and 30% using automatic data preparation and rule settings.
Return reusable rules, physical cutoffs and a complete prompt for generating 20 candidates.
```

Use `O2` for oxygen permeability, or supply measured selectivity as a separate target. For the public gas CSV, the structure column is `Smiles`.

## Thermal and optical materials

For thermal conductivity:

```text
Learn high-thermal-conductivity rules from my uploaded thermal.csv with STCA.
Structure column: SMILES; computed target: ThermalConductivity; unit: W/(m K).
Explore Top 10%, 15%, 20%, 25% and 30% with automatic settings.
Return the rules, reusable model and a copyable generation prompt.
```

For optical materials:

```text
Learn high-refractive-index rules from my uploaded optical.csv with STCA.
Structure column: SMILES; computed target: RefractiveIndex; unit: dimensionless.
Explore Top 10%, 15%, 20%, 25% and 30%.
Return the rules and a generation prompt, then screen my uploaded candidates.csv.
```

For glass-transition temperature, you can select the published high-Tg rule from the catalog or learn a rule from your own `Tg` values, declaring their unit, such as K.

## Density and specific heat

You can directly select a [RadonPy high-density rule](../../docs/RULE_LIBRARY.md#radonpy-five-computed-properties). To learn low-density rules from your own data:

```text
Use STCA to learn low-density rules from my uploaded density.csv.
Structure column: SMILES; target: Density; unit: g/cm3; these are computed values.
Explore Bottom 10%, 15%, 20%, 25% and 30% with automatic settings.
Return a reusable model and a prompt for generating 20 low-density candidates.
```

For specific heat, use the same request with target `Cp`, unit `J/(kg K)`, direction `high` and your chosen Top percentages.

## Dielectric materials

Choose the direction for your application:

```text
Use STCA to learn low-dielectric-constant rules from my uploaded dielectric.csv.
Structure column: SMILES; computed target: DielectricConstant; unit: dimensionless.
Explore Bottom 10%, 15%, 20%, 25% and 30%.
Return the rules, model and a copyable generation prompt.
```

Choose direction `high` and Top percentages for a high-dielectric-constant task. Electrical-conductivity rules are separately listed in the built-in catalog.

## Isolated-monomer HOMO–LUMO gap

The ADEPT target is the DFT HOMO–LUMO gap of a hydrogen-capped isolated monomer. Ask for an included rule first:

```text
List the built-in monomer HOMO–LUMO-gap rules and their percentages.
From my selected rule, give me a complete prompt to generate 20 repeat units
with two terminal * connection points and a CandidateKey,SMILES CSV output.
```

To learn your own rule, upload a labeled CSV and specify its structure column, gap column, unit `eV`, direction and percentages.

## Use your own data and generate candidates

Your labeled CSV needs repeat-unit structures and a numeric property column. Tell STCA the column names, property unit, experimental/computed label type, direction and desired percentages. Optional IDs can have any name; original star-containing SMILES are retained.

```text
Use STCA on my uploaded materials.csv.
Structure column: RepeatUnit; target: MyProperty; unit: [my unit].
The values are [experimental or computed]. I want [high or low] values at [my percentages].
Automatically learn the rules and return a reusable model and a complete generation prompt.
```

The percentages are your choices; the lists above are examples. To combine targets, ask STCA to apply separately selected or learned rules to the same candidates—for example, high thermal conductivity plus low density, with a percentage for each property.

Copy a generated prompt into the current LLM or another LLM. Then upload the returned candidate CSV to the STCA-enabled host:

```text
Verify these generated candidates against the rules used in my prompt.
Keep original SMILES and return each passed and failed condition, plus the matching candidates.
```

If your table already contains a training/test split, tell the skill the column and label names to preserve. See the [main guide](../../README.md) for installation and the three core workflows.
