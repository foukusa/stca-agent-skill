## 打开主菜单

```text
开始使用 STCA。
```

STCA 显示三个选项：

1. 上传自己的文件总结规则。
2. 根据已有规则直接筛选。
3. 根据已有规则生成候选。

随时发送 **“返回主菜单”** 或 **“上一级”**，已保存的规则会保留。明确提出一个完整任务时，也可以直接执行。

## 试用开源数据案例

想直接试用筛选，可上传随包的 [5 条候选示例 CSV](../examples/quick_start/candidates.csv?raw=true)，也可发送：

```text
使用内置含氟候选示例，按 RadonPy 高密度 Top 30% 的 STCA 规则筛选，并给出每条失败条件。
```

你会得到 3 条结构规则匹配和 2 条未匹配，原始带星号 SMILES 及每条失败条件均保留。

想试用规则归纳，下载 [GAS Dataset A CSV](https://github.com/jsunn-y/PolymerGasMembraneML/blob/30981d71e1e3f12a057e009cd79f119bc659c7f5/datasets/datasetA_imputed_all.csv)，上传后发送：

```text
从这份实测 CO₂ 渗透率数据总结高值规则，单位 Barrer，考虑 Top 10%、20%、30%。自动调整数据形式与步长，返回各档筛选结果并保存规则。
```

AI 助手会使用原始实测 `CO2` 列，而不是 Bayesian 或 Etree 插补列，返回规则、自动选择的设置和筛选结果，保存规则后回到主菜单。随后可说“使用刚保存的 Top 20% STCA 规则，筛选这份新候选表”。

## 1 上传文件总结规则并取得筛选结果

上传带有结构和数值性质的 `materials.csv`，例如自己的计算热导率表，然后发送：

```text
1。从这份计算数据总结高热导率规则，单位 W/(m K)。
```

若列名或数据含义不明确，STCA 只补问必要信息。未指定百分比时，高值直接使用 Top **10%、20%、30%**，低值直接使用 Bottom **10%、20%、30%**。STCA 在你的数据范围内比较 STCA 与 WRAcc，两种方法分别交付，逐档给出主推及备选，保存后回到主菜单。

可指定 0% 与 100% 之间的任意百分比，也可补充“保存为我的高热导”。例如：

```text
从这份实测 CO₂ 渗透率数据总结高值规则，单位 Barrer，使用 15%、25%。分别给两种方法的结果和每档具体数值阈值，并自动推荐方法。
```

每档都显示原始物理尺度的具体阈值：高值用 ≥，低值用 ≤，并带单位；即使用 log10 归纳，也返回物理阈值。

推荐依据 **AS = (MCC + Precision + F1) / 3**。两种方法均可评价时，只有 WRAcc 的 CV AS 高出 STCA **超过 0.02** 才主推 WRAcc，否则保留 STCA。两种方法的分数、各自入选结果和推荐理由同时返回。说“使用推荐结果”或“自动选方法”就直接采用主推，不再增加方法确认；明确指定方法时按你的选择执行。

你会得到：

- 本次各档位的 STCA 与 WRAcc 规则、分数、主推／备选及推荐理由，以及具体物理阈值、比较符、单位和可复用模型。
- 每种方法在各档位的逐条筛选结果：原始 SMILES、是否入选、每条失败条件及不可计算记录。
- 完整中英文生成 prompt，以及保存后的友好名称和可下载规则包。
- 任务完成后的主菜单；刚保存的规则可继续用于选项 2、3。

原上传表始终返回逐档筛选结果。如果同时上传了独立的 `candidates.csv`，其结果另列，可以加一句：

```text
请将各档规则应用到我另外上传的 candidates.csv，返回它的筛选结果。
```

某档位正例不足 20 时会注明评价样本不足，仍可学习并保存规则。没有有效规则或无法计算的档位会返回状态和原因。

若你提供了 source／holdout 角色，或明确要求外推检验，STCA 会使用相应的独立留出流程，设置只在 source 内决定。默认的数据范围内评价按重复单元结构分组；评分针对自动预处理后的数据。

## 2 根据已有规则筛选候选

上传自己的候选表，或者先用[结构输入示例 CSV](../examples/candidates.csv)。示例只含结构，不含实测性质。也可直接说“先用内置候选示例演示筛选”，无需自己制作 CSV。

```text
2
```

STCA 自动展示内置规则和已保存的“我的规则”，每项给出来源、性质、方向、百分比，以及方法与主推／备选。随后可回复：

```text
使用作者归档的高 Tg Top 20% 规则，筛选我上传的候选表。
```

开源数据内置 Top 10%、20%、30%。例如也可选择“GAS 高 CO₂ 渗透率 Top 10% 主推规则”；接受推荐会直接使用主推，明确指定 STCA 或 WRAcc 时按你的选择执行，两套规则分别筛选。选定档位后显示具体物理阈值、比较符和单位。所需百分比不在冻结目录时，需要带标签数据学习该档，不能插值或替换成相邻百分比。

如果已完成上一个案例，也可回复：

```text
使用刚保存的规则筛选这份候选表。
```

结果保留所有原始 SMILES 和标识，返回入选结果、每条失败条件及无法判定记录，然后回到主菜单。用随包的 5 条结构示例选择上述作者归档高 Tg Top 20% 规则时，会得到 2 条匹配与 3 条未匹配；这演示结构规则检查，示例没有物性标签。

## 3 先选择规则再生成候选

```text
3
```

STCA 自动先显示**内置规则＋已载入的“我的规则”**，包括各档的方法及主推／备选。选定数据来源、性质、百分比和所用规则后，再选择以下两种方式。也可以选择刚保存的规则。

**先预览，确认后生成。** 发送：

```text
使用作者归档的高 Tg Top 20% 规则，生成 20 个候选前先给我看完整 prompt。
```

STCA 展示完整 prompt，等待你的确认。可用自然语言调整，例如：

```text
数量改成 10 个，优先考虑含醚键的结构，再给我看修改后的 prompt。
```

满意后回复：

```text
确认，开始生成。
```

当前 LLM 会使用已确认的 prompt 生成候选并核验。候选数量、结构偏好和输出格式都可调整；修改目标或冻结规则条件时，会重新选择并确认对应规则。

**直接生成。** 发送：

```text
使用作者归档的高 Tg Top 20% 规则，直接生成 20 个候选并核验。
```

当前 LLM 立即按选定规则生成。无需另外配置 LLM API。没有指定生成方式时，STCA 会在选好规则后展示这两个选项。

两种方式都保留全部原始提案、带星号 SMILES、规则判断和每条失败条件，分别报告生成总数和规则通过数，完成后返回主菜单。

## 只获取生成 prompt

在规则目录选定目标后发送：

```text
只给我这条规则的完整中文生成 prompt，暂不生成结构。
```

复制 prompt 到其他 LLM 后，将生成的候选表上传回来，发送 **“按同一规则核验这些候选”**。

## 换会话或平台继续使用

下载前一次返回的规则包，在新会话上传并发送：

```text
载入这个规则包，显示主菜单，并把这些规则放入“我的规则”。
```

之后选择 2 或 3 即可复用，无需重新训练。返回菜单不会删除规则；跨设备继续使用时携带规则包。

## 可选多目标筛选

上传候选表后发送：

```text
同时使用作者归档高 Tg Top 20% 和低电导率 Bottom 10% 规则筛选。
给出每个目标的判断、每条失败条件以及同时满足的候选。
```

各目标分别选择百分比。STCA 核验结构规则，实际物性是否达到目标需依据相应验证结果判断。
