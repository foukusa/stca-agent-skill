# STCA 如何评价新规则

[English](MORGAN_EVALUATION.md) · [使用说明](USAGE.zh-CN.md)

新规则归纳默认采用 **Morgan 距离定义的 interpolation／extrapolation 划分**。AI 助手自动完成划分并返回核验依据，用户使用自然语言即可。

1. **先按结构划分。** 对 H-cap 计算副本计算 2,048 位、radius=2 的 Morgan 指纹（ECFP4），距离为 1 − Tanimoto 相似度。相同原始重复单元和相同 H-cap 副本保持同侧；性质数值不参与划分选择。
2. **分离外推结构。** 在结构空间外围选择一个邻域作为 extrapolation 区域，目标约占有效结构记录的 20%。将与其距离不足 0.5 的其他结构组放入相似性缓冲区，其余为 interpolation 区域。每条 extrapolation 结构到 interpolation 区域的最近邻距离必须 **至少为 0.5**。
3. **仅在 interpolation 区域学习。** 数据变换、扫描步长和支持量在该区域内确定；其中另做 Morgan 距离验证，比较 STCA 与 WRAcc。在查看外推评价结果前冻结方法推荐。
4. **评价冻结规则。** 两种方法使用训练得到的具体性质阈值及单位。返回 extrapolation 区域的精确率、召回率、F1、马修斯相关系数和平均筛选评分，并给出样本数及实际距离。
5. **交付规则和筛选结果。** 保存训练得到的规则及阈值；另行筛选原始上传表。原表匹配包含训练记录，与独立外推评价分别报告。

平均筛选评分来自作者 [STCA 论文](https://doi.org/10.1038/s41524-026-02345-x)，定义为 **（马修斯相关系数 + 精确率 + F1）/ 3**。两种方法都有可用的内部验证证据时，WRAcc 得分高出 STCA 超过 0.02 才推荐 WRAcc，否则保留 STCA。证据不足时单独说明状态。

距离划分无法成立，或外推区域只有一种目标类别时，明确返回不可用原因，不静默换成随机划分。测试样本少、指标未定义等状态按实际情况保留。

## 内推范围、内部验证与外推

| 数据部分 | 分割方式 | 用途 |
|---|---|---|
| interpolation 区域内评价 | 相同原始结构或相同 H-cap 副本保护成组，随机分组 5 折、重复 3 次 | 查看内推范围的规则表现；沿用该区域的数据准备，不是另设的独立内推测试集 |
| interpolation 区域内部 Morgan 验证 | 在训练区域中再次按 ECFP4 距离划分，最近邻距离 ≥0.5 | 在外推评价前选择 STCA 或 WRAcc |
| 独立 extrapolation 区域 | 仅按结构选择外围邻域，默认约 20%；相似性缓冲区确保与 interpolation 区域的最近邻距离 ≥0.5 | 检验规则向明显不同结构的迁移 |

采用这种分割，是为了避免相同或高度相似结构跨越 interpolation 与 extrapolation 边界，并用可核验的化学结构距离定义外推。相似性缓冲区不用于训练或外推评分，仍参与原表筛选。interpolation 区域内部的 Morgan 验证也是距离分离的验证；它与该区域的 5 折范围内评价分开，当前没有另外单列的独立内推测试集。

论文预置规则保留原条件及原评价协议。

百分比定义训练标签的目标尾部，不是候选入选配额。各百分比独立准备。返回 SMILES 保留原始 `*` 连接点，H-cap 只用于计算副本。
