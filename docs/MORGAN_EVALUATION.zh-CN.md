# STCA 如何评价新规则

[English](MORGAN_EVALUATION.md) · [使用说明](USAGE.zh-CN.md)

新规则归纳默认采用**严格 Morgan 距离留出**。AI 助手自动完成划分并返回核验依据，用户使用自然语言即可。

1. **先按结构划分。** 对 H-cap 计算副本计算 2,048 位、radius=2 的 Morgan 指纹（ECFP4）。相同原始重复单元和相同 H-cap 副本保持同侧；性质数值不参与划分选择。
2. **留出远距离结构。** 每条留出结构到 source 结构的最近邻 Tanimoto 距离必须**至少为 0.5**。边界记录可进入明确报告的 buffer；buffer 不用于训练或留出评分。
3. **仅在 source 中学习。** 数据变换、扫描步长和支持量由 source 数据确定；在 source 内另做 Morgan 距离验证，比较 STCA 与 WRAcc。在查看外部留出结果前冻结方法推荐。
4. **评价冻结规则。** 两种方法使用 source 得到的具体性质阈值及单位。返回留出集的精确率、召回率、F1、马修斯相关系数和平均筛选评分，并给出样本数及实际距离。
5. **交付规则和筛选结果。** 保存 source 训练的规则及其阈值；另行筛选原始上传表。原表匹配包含训练记录，不能当作独立留出表现。

平均筛选评分来自作者 [STCA 论文](https://doi.org/10.1038/s41524-026-02345-x)，定义为**（马修斯相关系数 + 精确率 + F1）/ 3**。两种方法都有可用的 source 内验证证据时，WRAcc 得分高出 STCA 超过 0.02 才推荐 WRAcc，否则保留 STCA。证据不足时单独说明状态。

距离划分无法成立，或留出集只有一种目标类别时，明确返回不可用原因，不静默换成随机划分。测试样本少、指标未定义等状态按实际情况保留。

早期保护结构组随机五折结果描述观测分布内的评价；早期 ECFP4–t-SNE 外围划分对应投影外围协议。两者都不能改称严格 Morgan 距离测试。作者 STCA 论文预置规则保持原条件及原评价协议。

百分比定义 source 标签的目标尾部，不是候选入选配额。各百分比独立准备。返回 SMILES 保留原始 `*` 连接点，H-cap 只用于计算副本。
