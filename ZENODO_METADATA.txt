Description:
STCA Agent Skill connects Sliding Threshold Correlation Analysis with agent workflows for polymer repeat-unit screening and design. It can apply frozen structural rules, extract and evaluate readable rule families from measured datasets, connect independently scaled Tg, Tm, Td, TC, EC and ε-AC objectives, and export executable constraints for candidate proposal followed by structural verification. The integration uses the pinned polymer-stca 1.0 implementation and preserves the STCA H-cap representation.
