Description:
STCA Agent Skill integrates Weihao Wang's original Sliding Threshold Correlation Analysis with agent workflows for polymer repeat-unit screening. It supports applying frozen published rules, extracting and evaluating interpretable presence/absence rules from measured datasets, and proposing candidates followed by explicit H-cap, RDKit MACCS and frozen-rule verification. The integration uses the pinned original polymer-stca 1.0 implementation. This release includes executable adapters, exact dependency files, public unlabeled candidate fixtures and aggregate validation evidence. A structural rule match does not establish a new measured property, synthetic accessibility or novelty.
